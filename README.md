# Brain Teaser Class 5

Maths practice for a class 5 pupil in Ireland. It runs in the browser and has no server, no sign-in and no stored data.

- Every question is generated with new numbers. The page never shows an answer.
- A wrong answer replaces the question with a new question of the same type.
- The score counts the questions that were correct on the first try.

Add a test: add one entry to the `TESTS` list in `index.html`.

Check the generators:

```bash
node tests/check-generators.js
```
